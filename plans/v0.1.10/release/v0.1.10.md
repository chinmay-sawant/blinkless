# Blinkless v0.1.10 Release Notes

Released 2026-11-27 on `master`, covering work after `v0.1.9` merged in PR #57 and PR #58.

## Highlights

`v0.1.10` cuts another 47% off CSS animation restamping ticks, eliminates 92.6% of remaining heap allocations on 1,000-row `DisplayList` layouts, adds incremental `position: absolute` splicing and `CustomProps` intern hashing, and introduces opt-in `Options.CullWindow` vertical viewport culling.

## What Changed

### 1. Incremental Relayout & Style Interning, PR #57
- **In-place `position: absolute` splicing (`internal/layout/relayout_subtree.go`).** Spliced moved `position: absolute` boxes in place and fast-pathed pure `left`/`top` translations (`tryAbsTranslate`), preserving containing-block geometry, inline leaf targets, and deduplicated ancestor splices while cloning shared `Grid` and `styles` maps safely.
- **Faster style interning and match caching (`internal/style`, `internal/layout`).** Cached `CustomProps` intern hashes, filtered unused attributes from `matchCache`, memoized base styles for inline `px` boxes, and removed a no-op XOR on nil custom-property hashes.

### 2. Allocation Elimination & Animation Restamping, PR #58
- **Zero-boxing `flowCBState` (`internal/layout/layout_height_context.go`, `layout.go`, `flex.go`, `grid_memo.go`).** Replaced `flowCBHeight *float64` with value struct `flowCBState`, eliminating ~4,000 heap allocations per 1,000-row layout.
- **Lazy box indices & pooled coverage mask (`internal/layout/layout_state.go`, `reproject.go`, `transform.go`, `layout/reproject.go`).** Lazily cached `idBoxes`, `boxParents`, and `boxOrder` on `Result` and `boxByID` on `Display`, turning `boxForID`, `findBoxAncestors`, `outermost`, and `restampedBoxes` from full-tree or linear scans into O(1) and O(depth) lookups. Reused a pooled `covered []bool` buffer in `restampBoxTransformsWithCovered` and a stack `[16]string` buffer in `splitTransformArgsInto`.

### 3. Text-Width Lookup & Flex Row Micro-Optimizations, PR #58
- **Partitioned per-style text-width maps (`internal/layout/text_measure_cache.go`, `layout.go`).** Split the per-layout string width cache by interned `styleID` into pooled `map[string]float64` submaps with a 1-slot `lastWidthStyleID` cache, switching lookups to `runtime.mapaccess2_faststr` and halving `aeshashbody` CPU time.
- **Style, face, and default-value fast paths (`internal/layout/layout.go`, `layout_faces.go`, `flex*.go`, `inline_paint.go`, `inline_vertical_align.go`, `mask_*.go`, `blend_group.go`).** Added a 4-slot `stylePtr` cache, threaded `*ResolvedStyle` through `flexMeas` and `flexPlacedItem`, checked `lastFaceForSty` before `variationCacheBits`, short-circuited empty/`none`/`baseline` defaults before `strings.TrimSpace`, and raised `maxPooledBoxSliceCap` to `8192`.

### 4. Opt-In Viewport Culling, PR #58
- **`Options.CullWindow` (`layout/layout.go`, `layout/displaylist.go`, `internal/layout/layout_flow.go`).** Added an opt-in vertical cull band (`TopPx`, `BottomPx`). When set, definite-height in-flow block/flex containers outside the band advance flow Y without laying out children or emitting ops, preserving exact canvas height and visible coordinates while cutting 1,000-row `DisplayList` time from `9.73 ms` to `1.24 ms`.
