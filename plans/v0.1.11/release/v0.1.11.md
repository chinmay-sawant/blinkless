# Blinkless v0.1.11 Release Notes

Released 2026-11-28 on `master`, covering retained DOM mutations, copy-on-write batch relayout, and `SheetVersion` stylesheet reuse after `v0.1.10`.

## Highlights

`v0.1.11` adds full retained DOM mutation APIs (`RemoveAttribute`, `AddClass`, `RemoveClass`, `ToggleClass`, `RemoveElement`, `SetInnerHTML`, `AppendHTML`), cuts 1,000-row `RelayoutElements` latency by **3.88x** (`471.5 µs` -> `121.5 µs`) and memory by **65.5%** via copy-on-write box graphs and lazy `OpOwners`/`Order` cloning, and adds `SheetVersion` so `css.Relayout` skips DOM sheet recollection on non-`<style>`/`<link>` leaf edits.

## What Changed

### 1. Retained DOM Mutation APIs (`html/mutate.go`, `html/attribute.go`)
- Added `RemoveAttribute(elementID, name string) bool` with HTML case-insensitive and SVG/MathML case-sensitive matching, `elementIndex` invalidation on `id` removal, and no-op stability.
- Added `AddClass`, `RemoveClass`, and `ToggleClass` with ASCII whitespace tokenization, duplicate suppression, and no-op stability.
- Added structural fragment mutations `RemoveElement`, `SetInnerHTML`, and `AppendHTML` with context-aware HTML/table/select/SVG/MathML fragment parsing, `elementIndex` synchronization, `ChildVersion` updates, and `DirtyStructural()` marking.

### 2. Copy-on-Write Batch Relayout (`layout/relayout_elements.go`, `internal/layout/`)
- **Copy-on-write box graph (`boxesShared`) & ancestor path-copying (`layout.go`, `layout_chunks.go`, `relayout_subtree.go`, `paint_restyle.go`, `abs_translate.go`).** `CloneResultForBatch` shares `root`/`boxes` instead of eagerly cloning all boxes on every batch, path-copying only the ancestor chain from `root` to `target.parent` on paint-only splices, paint restyle, and abs-translate, and materializing on demand for non-paint-only splices.
- **Lazy `OpOwners`/`Order` cloning & `countOrderingRelevant` (`relayout_elements.go`, `relayout_subtree.go`).** Paint-only batches reuse `prev.OpOwners` and `prev.Order` without copying and skip full-list ordering scans.
- **Faster `cloneOps`, O(1) `boxIndexByID`, and single `thread.lookup` (`clone_ops.go`, `relayout_elements.go`, `relayout_subtree.go`).** Added early return in `cloneOps` when no op owns extras, deduplicated identical ancestor text splices in `applyPaintOnlyBoxTexts`, reduced `thread.lookup` from 3x to 1x per ID, and fixed a latent `stylesShared` clone bug in `commitPaintRestyle`.

### 3. `SheetVersion` Fast Path (`internal/html/html.go`, `html/`, `css/css.go`, `css/relayout.go`)
- Added `NonSheetMutations` and `Node.SheetVersion()` so non-structural edits on non-`<style>`/`<link>` elements keep `SheetVersion` unchanged, allowing `css.Relayout` to reuse collected sheets without walking the DOM while `<style>`/`<link>` edits, structural mutations, and direct `MutationVersion` bumps still force recollection.
