# v0.0.3 - Animation and view transitions

> **Parent:** `plans/v0.0.3/README.md` - index of these ledgers.
> **Status:** not started. Baseline rows record what the code already does. Implementation rows are open.
> **Estimated effort:** 32 CSS property names (23 unprefixed, 9 `-webkit-animation*` aliases) across 8 phases.

---

## Overview

Blinkless returns a drawing list. The Go type is `layout.Display` from `layout.DisplayList` (`layout/displaylist.go:129-138`). A host replays the operations. This tree does not encode a page PNG, does not write a PDF, and does not run JavaScript. It also has no clock that samples animation frames.

This ledger stores animation data so a host can sample time itself. The data is keyframe rules, per-element timing, and the properties each keyframe sets. Blinkless does not interpolate and does not change paint because time passed.

The 32 names are the 23 unprefixed properties in the executive summary plus the nine `-webkit-animation*` aliases. `documentation/deferred.md:110` still calls a wider set of 45 names a permanent print non-goal. That sentence also covers transitions (the transitions ledger), `pointer-timeline*` (the scroll ledger), and `event-trigger*`, `timeline-trigger*`, and `image-animation` (not this ledger). `documentation/compatibility-matrix.md:1122` is the same 45-name list. `documentation/deferred.md:120` puts the nine animation aliases in vendor group D. This file is the planning home for the 32 names. Do not edit `deferred.md` in the planning session. Phase 5 points that row here after the tests exist.

`trigger-scope` and the four `view-transition-*` names are in this file because they travel with the animation family in the catalog. They are element identity for a host. They do not start a view-transition engine.

## Phase 0: lock the contract and the baseline

### 0.1 What the code does today

- [x] The public pipeline is `html.Parse` (`html/parse.go:36`), `css.Apply` (`css/css.go:98`), and `layout.DisplayList` (`layout/displaylist.go:137`). `css.Options` is `WidthPx`, `HeightPx`, `Media`, `Extra`, `Focus`, `Hover`, and `Active` (`css/css.go:69-78`). `Media` is screen or print. Any other token, including `speech`, returns `ErrBadMedia` (`css/css.go:147-155`, test at `css/css_test.go:58-60`).
- [x] `layout.Box` is the element border box in CSS pixels: id, tag, action, text, X, Y, W, H (`layout/layout.go:10-21`). `PlacedElement` is those same fields in points (`internal/layout/placed.go:7-16`). `boxesFrom` copies them and converts points to CSS pixels (`layout/layout.go:35-48`). WASM `drawBoxJSON` copies the same six fields (`bindings/wasm/drawing_list.go:194-203`, loop at `296-309`). None of those structs carry animation, keyframes, or view-transition names.
- [x] The WASM schema string is `blinkless.drawinglist/1` and the numeric version is 1 (`bindings/wasm/drawing_list.go:20-23`).
- [x] `@keyframes` and `@-webkit-keyframes` are not stored. `parseNonConditionalAtRule` calls `skipAtRule` (`internal/css/css.go:296-298`). `skipAtRule` consumes the block and returns the rest of the sheet (`internal/css/css.go:560-570`).
- [x] A property with no apply arm still passes `supportedDeclaration` when it is not in the acceptance table (`internal/layout/style_value_accept.go:135-138`, default at `607-608`). The cascade keeps it (`internal/layout/style_cascade.go:693-695`). `applyStyleProp` then calls `applyIgnoredGroup` (`internal/layout/style_cascade.go:1879-1885`). That function drops the name and the value (`internal/layout/style_properties.go:1854-1859`). Its comment says it ignores the animation and transition family. The body drops every unclaimed name.
- [x] `@supports` is `engineSupportsProperty` (`internal/layout/style_cascade.go:1888-1920`). It returns true only when some function in `styleGroups` returns true. `styleGroups` has no animation function. The last entry is `applyScrollProps` (`internal/layout/style_cascade.go:1642-1676`). - [x] `-webkit-animation*` is not rewritten. `normalizeVendorPrefix` (`internal/layout/style_cascade.go:1679`) handles mask names and then `normalizeOtherWebkitProperty` (`1717-1742`). That function has no animation case. A search of `internal/layout/*.go` found no `-webkit-animation` string.

### 0.2 Contract to implement

- [ ] Store one animation record per comma-separated index on the element, after list alignment, so duration, delay, timing, count, direction, fill, play state, composition, name, timeline, and range for index i stay together. Do not store side-by-side lists the host can get out of step.
- [ ] Store keyframe rules once on `layout.Display`, not once per element. Each rule has a name and a list of offsets. `from` is offset 0 and `to` is offset 1. Each offset stores the property names and the specified values set at that offset, including properties this engine does not paint. A test with `@keyframes slide { from { opacity: 0 } to { opacity: 1 } }` fails if opacity is missing from that table.
- [ ] Do not invent the `@keyframes` cascade rule. Read it from the css-animations spec linked by the upstream row before deciding whether two rules with the same name replace or combine. The test names the rule it uses.
- [ ] The element record stores the keyframe name and the timing. The host samples time and writes the interpolated values. Blinkless does not build intermediate paint ops.
- [ ] Times are milliseconds and may be negative only where the syntax says `<time>` rather than `<time [0s,inf]>`. Lengths that describe box geometry are CSS pixels, the unit `layout.Box` already uses (`layout/layout.go:10-11`). Keywords stay keywords. A behavior test always uses a non-initial value so a missing field fails.
- [ ] `animation-trigger` and `trigger-scope` are stored names. Nothing in this tree activates them. `DisplayList` returns paint operations (`layout/displaylist.go:129-138`). It does not attach event listeners.
- [ ] View-transition fields are stored on the element. This ledger does not capture before and after snapshots.
- [ ] `-webkit-animation*` maps onto the unprefixed name inside a helper called from `normalizeOtherWebkitProperty` (`internal/layout/style_cascade.go:1717`), the same pattern as the other prefix maps. One applier. Source order between prefixed and unprefixed declarations stays the cascade order already implemented at `style_cascade.go:691-698`.
- [ ] New parse code lives in `internal/css/keyframes.go`, called from `parseNonConditionalAtRule` instead of `skipAtRule` for these two at-rules only (`internal/css/css.go:296-298`). New apply code lives in `internal/layout/animation_style.go`. New copy code lives in `internal/layout/animation_payload.go`. `ResolvedStyle` fields stay on the struct in `internal/layout/style.go`. Regenerate interning from the `go:generate` line at `internal/layout/style.go:2`. Register `applyAnimationProps` as one new entry in `styleGroups` (`internal/layout/style_cascade.go:1642`). Do not add lines to `internal/layout/layout.go`.
- [ ] Public fields go on `layout.Box` (`layout/layout.go:12`) and are copied in `boxesFrom` (`layout/layout.go:35`). Keyframes go on `layout.Display` (`layout/displaylist.go:102`). WASM adds fields on `drawBoxJSON` and on the top-level JSON in `newDrawingList` (`bindings/wasm/drawing_list.go:282-325`). Tag them `omitempty` so an empty value is left out of the JSON. Schema stays `blinkless.drawinglist/1`. A test fails if the schema string changes.
- [ ] A name is done only when a handler stores it, the public box or the keyframe table shows it, and a behavior test fails if that value is removed. Catalog status is not that proof (`testdata/css/catalog/properties.json:9`).
- [ ] The in-engine clock is not part of this contract. It is the phase 7 non-goal.

**Gate:** this phase is locked when the rows above are either checked baseline or still open on purpose. No paint change is allowed to land before the keyframe table and the box record exist.
