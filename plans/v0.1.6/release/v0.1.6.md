## Summary

v0.1.6 is a correctness and hardening release with one user-visible feature. It follows two independent Go code reviews of v0.1.5 and closes the findings from both: memory leaks, two data races that kept ownframe behind a global engine lock, CSS selector and custom-property bugs, unbounded caches, and a CI setup that ran almost none of the checks the Makefile advertised.

The one feature is automatic system CJK font fallback. Han, kana, Hangul, and fullwidth text that no declared or bundled face covers now draws with an installed operating-system font instead of missing-glyph boxes.

Highlights:

| Area | What changed |
| --- | --- |
| **Concurrency** | `Node.EnsureAttrs()` race, `prepare.SheetCache` concurrent map write, and a shared mutable transitions slice are fixed. A downstream host can drop its global engine lock. |
| **Memory** | `html.Document` no longer leaks through global registries. `ResolvedStyle` drops from 5,872 to 512 bytes. Raster and style caches are bounded. |
| **CSS correctness** | Descendant and general-sibling selectors backtrack. UTF-8 offset bugs, custom-property resolution, nested `@media`, and `@supports` case handling are fixed. |
| **Fonts** | System CJK fallback with TrueType collection (`.ttc`) support. |
| **CI** | Race, fuzz, wasm, vulnerability, claim, catalog, and matrix jobs now run. golangci-lint moves to v2.15.0 with no blanket `nolint:all`. |

## Breaking changes and behavior changes

No exported function was removed. These changes can still alter output or results for existing callers.

| Change | Who is affected | What to do |
| --- | --- | --- |
| CJK text can lay out and paint differently on machines with CJK fonts installed (#47) | Anyone rendering Han, kana, Hangul, or fullwidth text | Call `layout.SetSystemFontFallback(false)` or set `BLINKLESS_SYSTEM_FONTS=off` to keep the old box rendering. Use `@font-face` to pin a face when output must match across machines. |
| Custom property names are case-sensitive (#48, #49) | Stylesheets that wrote `--Brand` and read `var(--brand)` | Match the case in both places. This follows CSS Custom Properties Level 1. |
| `html.Parse` rejects sources over 64 MiB (#48) | Callers parsing very large documents | Use the new `html.ParseWithLimit(source, maxBytes)` with a larger bound. |
| `var()` chains deeper than 64 levels resolve to empty (#48) | Pathological or cyclic custom-property chains | Flatten the chain. |
| `Display.Boxes` is nil after `Release()` (#48) | Callers that read boxes after releasing a display | Read boxes before `Release()`. The ownership contract is now documented and tested. |
| HTTP loads are GET-only; cookie and POST loading are removed (#48) | Callers that used `internal/load` cookie or POST paths | None of these were part of the public API. Fetch such resources yourself and pass the bytes in. |
| `css.Apply` clones `opts.Extra` (#48) | Callers that mutated the map after the call and expected the engine to see it | Pass the final map before calling. |
| `go.mod` directive is `go 1.26.0` (#48) | Module consumers | Toolchain `go1.26.4` is unchanged. |

Dependency moves, all indirect: `golang.org/x/net` v0.55.0 to v0.60.0, `golang.org/x/image` v0.41.0 to v0.43.0, `golang.org/x/text` v0.37.0 to v0.42.0, `github.com/andybalholm/brotli` v1.2.1 to v1.2.7. The direct-dependency allowlist (`TestDirectModuleAllowlist`) is unchanged and the runtime is still pure Go with `CGO_ENABLED=0`.

## Upgrade notes for ownframe and other hosts

- Two races were the reason ownframe serialized every engine call behind `internal/render/engineMu`: lazy attribute-map materialization (`Node.EnsureAttrs()`) and the shared `prepare.SheetCache`. Both are fixed in #48 and covered by `go test -race` over `./css`, `./layout`, `./html`, `./markup`, and `./internal/...`. A host can now remove that lock once it pins this release.
- Bump the `blinkless` pin in the host's `go.mod` (and any example module that mirrors it). The `go 1.26.0` and indirect dependency bumps above must be mirrored.
- Expect CJK glyphs where boxes used to appear when the host machine has a CJK font. Windows, macOS, and WSL are covered by the candidate list; most Linux distributions ship Noto Sans CJK as CFF, which is skipped (see Fonts below).
- Hosts that call `html.Parse` on untrusted input get a 64 MiB cap for free. Hosts that parse larger trusted input must switch to `ParseWithLimit`.

## Features

### System CJK font fallback (#47, `a040f82`, `73cea67`, `c4393d9`)

Before this change the bundled faces (Liberation, DejaVu) had no CJK glyphs, and system font discovery was opt-in. Japanese text typed into an ownframe field rendered as boxes on a machine that had Japanese fonts installed.

- New `internal/fonts/system_fallback.go` finds candidate files per OS. Windows reads the font folder under `%WINDIR%` for Yu Gothic, Meiryo, MS Gothic, BIZ UD Gothic, Microsoft YaHei and JhengHei, SimSun, and Malgun Gothic, with bold variants. macOS reads Hiragino, PingFang, Apple SD Gothic Neo, and Arial Unicode. Linux and Android scan the font roots by file name for TrueType CJK families. WSL also reads `/mnt/c/Windows/Fonts`.
- It serves only CJK and fullwidth code points (`systemFallbackRune`). A Latin-only document never reads a font file.
- Each file is read and parsed once, on the first lookup that needs it. Every answer, including a miss, is cached per code point. A loaded face stays resident for the life of the process.
- `internal/fonts/ttc.go` adds `SplitTTC`, which rebuilds each member of a TrueType collection as a standalone SFNT so shapers that load one face per byte slice keep working. Windows ships its Japanese faces as `.ttc`. CFF (`OTTO`) faces are skipped, so Noto Sans CJK is not used on most Linux distributions.
- `registryGlyphFallback` in `internal/layout` consults the system fallback after the opt-in registry, only when nothing else covers the rune.
- Public API in `layout`: `SetSystemFontFallback(bool)` and `SystemFontFallbackEnabled()`. Environment variable `BLINKLESS_SYSTEM_FONTS=off` starts with it disabled.
- Cost: none for text without CJK. The first CJK character reads one file (about 10 MB for Yu Gothic) and measured 0.17 s including the read on the test machine. Later lookups are map hits.
- Tests: layout tests pin the bundled faces in `TestMain` so advances and op counts do not depend on the machine. `TestSystemFallbackHostCJK` and `TestSystemFallbackFaceForCJK` use the host's real fonts and skip where none exist. A new `FuzzSplitTTC` target covers the collection splitter. Verified end to end on Windows 11 with the Microsoft Japanese IME in ownframe's `examples/login`. The macOS and Linux candidate lists follow platform conventions and were not exercised on those hosts.
- Docs: `documentation/fonts.md`, `CHANGELOG.md`, `plans/PR/pr-system-cjk-font-fallback.md`.

## Fixes

### P0 correctness and memory (#45, `683ff1a`)

From a review of v0.1.5.

- **`html.Document` leak.** The element index and dirty set lived in global `elementRegistry` and `dirtyRegistry` maps with an unreachable finalizer, so every document stayed reachable forever. They are now unexported fields on `html.Document`. Test: `TestDocumentCollectibleAfterIndexAndDirtyUse`.
- **`CloneResult` ownership.** `CloneResult` now clones `Result.styles` with `maps.Clone` and leaves `styleChunks` and `storeChunks` unowned until a batch commits through `TransferChunksTo`. An aborted `RelayoutElements` batch leaves `prev` intact, and releasing a clone next to its source can no longer double-free pooled chunks. Tests: `layout/relayout_batch_isolation_test.go` and `TestRelayoutElementsAbortedBatchLeavesPrevIntact`.
- **Blend-group splice leaks.** `relayoutGroupWindow` is now wired into `RelayoutSubtreeWithOverrides` and `spliceOverridePatch`, and `widenGroupWindow` strips stale begin and end markers when a patch removes a blend group. This fixes orphaned markers after hover-leave drops `backdrop-filter` or `isolation: isolate`. Tests: `layout/relayout_group_hover_test.go`.
- **`Path.Points` aliasing.** `cloneOpExtraInto` now deep-copies path points during slab cloning, matching `detachedExtraCopy`, so mutating a cloned op cannot change `prev.Ops`.

### P1 correctness (#45)

- **Stacking contexts on ancestor paint replay.** `relayoutEnterAncestorPaint` and `pushZ` use `initiatesBlendGroup(style)` rather than `MixBlendMode != blendNormal`. An empty `MixBlendMode` no longer forces `zIndexSet`, `backdrop-filter` contexts are included, and explicit ancestor `z-index` bands are preserved.
- **`clip-path: ellipse(...)`.** `resolveEllipseRadii` resolves `rx` and `ry` independently, so mixed radii no longer collapse to one axis.
- **`outline-style: solid`.** Outline guards use `outlinePaints(sty)`, so a solid outline paints at the default `medium` width.
- **Raster effect caches.** `internal/layout/image_effect_cache.go` replaces clear-the-whole-map eviction with a bounded byte LRU: 256 entries, 512 KiB per entry, 32 MiB total, entries stored as exact-capacity clones. `hasEffect` now matches the filter kinds that are actually implemented.
- **Reflection-free hover restyle.** `paintOnlyBGDelta` no longer copies two 11.7 KB styles and calls `reflect.DeepEqual`. A generated `styleInternEqualExceptBG(a, b *ResolvedStyle)` from `scripts/gen-style-intern` replaces it.

### P0 concurrency and engine correctness (#48, `2426019`)

- **`Node.EnsureAttrs()` race (`BLK-CONC-01`).** Read-only passes in `css/hover_scopes.go`, `internal/layout/subtree_reuse.go`, `layout_svg.go`, and `layout/relayout_element.go` no longer materialize `Node.Attrs` lazily. A non-mutating `Node.AttrMap()` serves them. Test: `TestDisplayListConcurrentSharedDocument` and `TestHoverChangedScopesConcurrentSharedDocument`.
- **`prepare.SheetCache` (`BLK-CONC-02`).** The cache shared across `css.Relayout` documents is now mutex-guarded, which removes a concurrent map write. Test: `TestRelayoutConcurrentSharesSheetCache`.
- **`transitionsFrom` (`BLK-CONC-03`).** It returned a globally cached slice that callers could mutate. Each `DisplayList` call now gets a fresh `Box.Transitions` slice. Test: `TestTransitionsNotSharedAcrossDisplays`.
- **Combinator backtracking (`BLK-CSS-01`).** Descendant (space) and general-sibling (`~`) matching in `leftmostMatch` and `matchPseudoWalk` now backtrack across candidate ancestors and siblings. Before, the first candidate was committed to and valid matches were missed.
- **UTF-8 offsets (`BLK-CSS-02`).** `FontFaceURLs` and `expandOneRepeat` computed byte offsets on a `strings.ToLower` copy, which changes length for some non-ASCII runes. Lookups are now ASCII-fold, so offsets match the source string. Fuzz target: `FuzzExpandRepeat`.
- **Custom properties (`BLK-CSS-03`, `BLK-CSS-04`).** `ResolveCustomProps` expands embedded `var()` in order through `ResolveVars` with a recursion cap of 64. Names keep their case through declaration parsing and `parseVarFn`.
- **Sibling cache invalidation (`BLK-CSS-05`).** `siblingEntryFor` went stale when a child was replaced by another of the same length. Child edits in the `html` package now bump `Node.ChildVersion`, and the sibling entry keys on it. Test: `TestSetTextBumpsChildVersion`.

### P1 edge cases (#48)

- **Nested `@media` (`BLK-CSS-06`).** `parseNestedAtRule` now handles `@media` inside nested at-rules.
- **SVG rasterization (`BLK-SVG-01`).** `internal/svg/raster.go` fixes the `ErrNilContext` sentinel and replaces a 1 ms polling ticker with a proper semaphore wait. A new `FuzzRasterizeSVG` covers it.
- **Gradients (`BLK-CACHE-02`).** Gradient rasterization guards `NaN` and `Inf` inputs and caps cached bytes.
- **Relayout ABA tag (`BLK-API-01`).** The tag in `internal/layout/relayout_subtree.go` can no longer collide after reuse. The `layout.go` doc comment that misdescribed it is corrected.
- **Parser bounds.** `html.Parse` enforces a 64 MiB default cap, and `html.ParseWithLimit` takes an explicit one. Test: `TestParseDefaultCapAndExplicitLimit`. `SetAttribute` keeps the case of foreign (SVG/MathML) attribute names (`TestSetAttributeKeepsForeignCase`).
- **`css.Apply`** clones `opts.Extra` so later caller mutation cannot reach cached state (`TestApplyClonesExtra`).
- **`Display.Release()`** ownership and the units of `Box` and `DisplayOp` coordinates are documented and covered by `TestDisplayReleaseOwnershipContract`.

### Review follow-ups (#49, `c63d3c5`)

Edge cases found when auditing #48.

- **Nested `@media` ordering and bound.** `joinMediaQuery` puts specific media types (`screen`, `print`) ahead of `all`, and the cross product of nested comma-separated queries is capped at 64 entries. Tests: `internal/css/nested_media_test.go`.
- **`@supports` and custom properties.** `parseSupportsDeclaration` preserves the case of `--*` names, so `@supports (--Brand: x)` agrees with the declaration parser.
- **`ResolveCustomProps` output.** Undeclared variable names no longer appear in the returned map as `--missing: ""`, and `var(...)` embedded in a fallback value is expanded.
- **Zero-allocation attribute reads.** `html.Node` gains `HasAttrs`, `AttrCount`, and `ForEachAttr`, and the read-only paths in `css`, `layout`, and `markup` use them, so small-attribute nodes allocate no temporary map per call. Tests: `internal/html/attr_map_test.go`.
- **Dead code removed.** Unreachable `matchLeftSibling` and `matchLeftAncestor` are gone, and `chainFail` is shared along the first candidate spine.
- **Pool headers.** The multicol and `oldToNew` slice pools are paired with header pools, which avoids a 24-byte slice header allocation on every `Put`.

## Performance and memory

- **`ResolvedStyle` from 5,872 to 512 bytes (#46, `f180531`).** Uncommon CSS properties moved into optional lazy groups, and immutable initial-value groups are shared across elements. Style access, inheritance, equality, hashing, and interning now go through the groups. `scripts/gen-style-intern` gained `groups.go` to generate the group-aware code. Size and copy-semantics tests pin the 512-byte core. Eight interleaved runs gave mixed results: invoice layout 3.2% slower, medium full apply 1.0% slower, medium relayout 6.7% faster. The win is memory, not speed.
- **Lock contention (#48).** `lookupAcceptVerdict` and `supportsMemos` count hits with `atomic.Uint64` and no longer take an exclusive lock on a cache hit (`BLK-PERF-01`). `testScrollOffsetOf` is gated behind an atomic flag so production overflow boxes skip a global `RLock` (`BLK-PERF-02`). `css.Relayout` skips the DOM walk and `Loader` creation when only `hover`, `focus`, or `active` state changed (`BLK-PERF-03`). `Document.Find` answers a repeated absent id under a read lock instead of a full DOM walk, and `sharedCompiledMu` is no longer held across `newRuleIndex` (`BLK-PERF-04`).
- **Cache bounds (#48, `BLK-CACHE-01`).** Five caches that previously froze at a size limit now evict, and `sharedScaledFaces` no longer pins `*Font` values: style cascade, accept-verdict, match cache, advance cache, and system-fallback caches.
- **Hover path (#45).** The reflection-free `paintOnlyBGDelta` and pointer-passing chrome helpers (`*ResolvedStyle` instead of a by-value copy) remove large copies on every paint-only hover.
- **Image effect caches (#45).** Bounded to 32 MiB with trimmed entries.

The benchmark rows in `plans/v0.1.6/go-review-hardening/` (`BLK-P1A-GATE-03`) record that before and after numbers for the lock and relayout changes were not captured in the implementing session and remain open.

## Hardening and tooling

### Lint

- `golangci-lint` moves from v1.64.8 to v2.15.0 (`BLK-LINT-03`), matching ownframe. `.golangci.yml` is now a curated list instead of `enable-all`, with `nolintlint` set to disallow unused, unspecific, or unexplained directives.
- Every file-top `//nolint:all` is removed from production code, including `internal/layout/multicol.go`, `helpers.go`, `layout_chrome.go`, `layout_svg.go`, `layout_measure.go`, `style_values.go`, `internal/html/tree.go`, and `internal/html/fragment.go`, along with the real diagnostics they hid (#45, #48).
- About 1,190 orphaned `//nolint` directives for linters that were disabled are stripped, and test-file blanket headers are removed.
- `bindings/wasm` is linted under `GOOS=js GOARCH=wasm` instead of being excluded.
- `make lint-frontend` runs `tsc --noEmit` for `frontend/` instead of printing a no-op message.
- Process-wide test bypass switches (`flexRowMemoBypass`, `simpleFlexHeightBypass`, `multicolMemoBypass`, `paintRestyleDisabled`, `maxSharedTextWidthEntries`, `testScrollOffsets`) moved onto a per-engine test config (`BLK-TEST-01`), which is what lets the `paralleltest` suppressions go.

### Dead code removed

`internal/convert/render`, `internal/profiling`, the dotted-key settings machinery in `internal/settings` (three files), and leftover `wkhtmltopdf` residue in `internal/settings` and `internal/load`. Unwired `resolveStylesRetainedWithContext` (with `style_retain.go` and its test) and the `bench-lib` target went in #45. Obsolete PDF and PNG benchmark and architecture reports were archived or replaced (`testdata/golden/benchmarks/`, `reports/critical-golang-architecture-review.md`).

### Catalog paths (#46, `4fd6396`)

Four view-transition catalog entries now point at `internal/viewtransition/catalog_test.go`, and `scripts/check-css-ownframe-integration.py` runs integration tests by the Go package named in each catalog reference. Before, the four moved ownframe view-transition tests were listed but never executed. `GOFLAGS=-v xvfb-run -a make catalog-ownframe-check` now runs all four.

## CI and Makefile

`.github/workflows/ci.yml` was rewritten (#45, #48). Actions are pinned by commit SHA, permissions are least-privilege, and these jobs run:

| Job | Runs |
| --- | --- |
| test + build | `CGO_ENABLED=0 go build ./...`, tests, `make golden` |
| **race** | `make test-race`, now over `./...` |
| lint | golangci-lint v2.15.0 and the file-size gate |
| claim, catalog, matrix | `make claim-scan`, `make catalog-check`, `make matrix-check` |
| wasm contract | `make wasm-test` |
| **fuzz smoke** | `make fuzz-smoke FUZZ_TIME=15s` over every target in `scripts/fuzz-targets.txt` |
| modules + govulncheck | `make mod-verify` and `make vuln` |

Makefile changes:

- `RACE_PKGS` defaults to `./...`. It used to cover three packages, which skipped `./css` (hover cache race test) and `./internal/pubstate`.
- New targets `fuzz-smoke`, `vuln`, and `mod-verify`. `bench-lib` is removed. `bench-engine` includes `./internal/style` (#49).
- Targets that referenced the nonexistent `./internal/convert` package are repaired. `make test-unit` excludes `/temps/` scratch trees.
- `make test-quick` now matches its comment: slow and wall-clock perf-budget tests call `testing.Short()` and skip under `-short`.
- The fuzz list grew from 8 to 10 targets: new `FuzzMatchSelector` (`./internal/css`) and `FuzzRasterizeSVG` (`./internal/svg`). The full list is in `scripts/fuzz-targets.txt`.
- `scripts/check-file-size.sh` prunes `./.worktrees` (#49).

## Known gaps carried past this release

- **`BLK-ARCH-01` (parked).** Splitting `internal/style` out of the roughly 103,000-line `internal/layout` package. Only the rule index moved. The measured dependency closure of `style*.go` reaches 217 of 246 non-test files, so the rest needs its own PR.
- **`BLK-DEP-01` (decided).** Keep `github.com/tdewolff/canvas` for SVG-as-image rasterization. It is about 3% of the native binary.
- **Open gate rows.** In the phase files, the full `make test`, `make lint`, and benchmark rows were marked pending when #48 merged. Run them against the release commit before tagging.
- **CJK on Linux.** Noto Sans CJK ships as CFF on most distributions and is not used. A bundled CJK face (for example Noto Sans JP, several MB) and per-glyph language preference for ambiguous Han characters are out of scope.
