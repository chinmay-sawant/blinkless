# Blinkless v0.1.8

Release on top of `v0.1.7` (`6bd675b`), closing CSS layout/paint/SVG/font conformance gaps and cutting incremental relayout overhead.

- Range: `v0.1.7` (`6bd675b`) through `chore/improvement2` (2026-11-25)

## Summary

| Area | What changed |
| --- | --- |
| **CSS Layout & Grid** | 2-value `gap`, percentage `scale()`, `visibility: hidden`/`collapse` chrome skip, `inherit` border/outline colors, `grid-auto-flow: column` implicit columns with `grid-auto-columns`, sparse grid row-pinned placement, and CSS Anchor Positioning (`anchor-center`, `span-*`, `position-try-order`, `flip-start`). |
| **Borders, Masks & Effects** | `border-image` gradient shorthand priority, `filter: blur(...)` blend-group payloads, `mask-origin`/`mask-clip` box insets, `mask-border` layer composition/outset/vertical tiling, and `color-scheme: dark` UA form-control defaults. |
| **SVG Cascade & Raster** | Inline `style` precedence over XML presentation attributes, `marker` shorthand/longhands, `paint-order` inheritance, `linearRGB` gradient stop subdivision, `color-interpolation-filters` style fallback, and `fill-rule`/`clip-rule: evenodd` emulation for self-crossing paths and polygons. |
| **Typography & Fonts** | Custom strings for `text-overflow` and `text-emphasis-style`, `font-width` horizontal glyph scaling, and lazy MIT-licensed `Blinkless OT`, `Blinkless Var`, and `Blinkless Palette` faces. |
| **Performance & Incremental Patches** | Reduced subtree relayout cloning, anchor scan, and ancestor text overhead; fixed retained table paint range shifting on incremental patches. |

## Breaking changes

None. No exported API signatures were removed or changed.

## Upgrade

Replace `github.com/chinmay-sawant/blinkless v0.1.7` with `v0.1.8` in `go.mod`.
