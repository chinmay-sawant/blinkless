# blinkless 0.0.2

0.0.2 is a security release. It sits on the 0.0.1 drawing-list engine.
HTML and CSS still go in. A drawing list still comes out. This tree does
not write a PDF, does not encode a page as PNG or JPEG, and does not ship
a `blinkless` command.

`v0.0.1` is already published at `108c2c9`. This note is the work after
that tag, through `9792e54`. The commit list is
[commits.md](commits.md). The controls are the closed ledgers
`plans/v0.0.1/security/01` through `09`.

## What changed

A hostile document now stops at fixed budgets instead of nesting, tiling,
or fetching without a ceiling.

- Stylesheet source over 32 MiB is rejected (`internal/css/css.go`, `maxStylesheetBytes`).
- HTML element depth stops at 1024 (`internal/html/tree.go`, `maxElementDepth`). The active formatting list stops at 1024 (`internal/html/formatting.go`, `maxActiveFormatting`).
- `html.Parse` still does not cap the byte length. `ParseWithLimit` does, and the default bound is 64 MiB (`internal/html/html.go`, `maxParseInputBytes`). Callers that parse untrusted bytes themselves must bound them.
- Dashed edges, text-decoration steps, and border-image tiles stop at 1024 (`internal/layout/layout_chrome.go`, `internal/layout/inline_paint.go`, `internal/layout/border_image.go`).
- Decoded images stop at 16 million pixels (`internal/layout/layout_images.go`, `maxImagePixels`).
- SVG `text`, `tspan`, and `textPath` are removed before raster, so that path does not load a system font (`internal/svg/strip_text.go`, `stripSVGTextElements`). Geometry still rasterizes. Text glyphs in that image disappear.
- Local files open through `os.Root`. A FIFO is rejected. Restricted mode refuses private and a few non-global addresses, and it refuses a hostname when a proxy is set (`internal/load/load.go`).
- The C binding caps the allow list and the last-error buffer, rejects an HTML length at or above 2^63, and recovers panics in the exports (`bindings/c/exports_cgo.go`). WASM applies the JSON and HTML byte caps after boxing the JavaScript string (`bindings/wasm`).

GitHub Actions on a branch and on a `v*` tag runs `make test` and `make lint` only. The tag is not compared to a version file.

## Removed

The Python package is gone: `bindings/python`, `.github/workflows/publish-pypi.yml`, `scripts/check_versions.sh`, and `make check-versions`. `bindings/c` and `bindings/wasm` stay. There is no `VERSION` file.

The Python call locks and the embedded-NUL check left with that package. The C allow-list cap remains.

## What still does not ship

PDF files, PDF profiles, the `blinkless` command, veraPDF, and a golden PDF corpus. One image operation is re-encoded as PNG when orientation or a clip requires it. That is not a picture of the page.

Public `html.Parse` has no byte cap. A canvas draw that has already started still finishes. A C caller must still pass a valid pointer. No document script runs, and that is not a proof that every bug is gone.
