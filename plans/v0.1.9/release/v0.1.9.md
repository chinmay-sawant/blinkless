# Blinkless v0.1.9 Release Notes

Released 2026-11-25 on `master` (work after `v0.1.8` / `787ca05`, merged in PR #56).

## Highlights

`v0.1.9` is a pure-Go performance release focused on eliminating allocator churn and redundant tree/font work across CSS animation restamping, large `DisplayList` layouts, viewport-only `css.Relayout`, and CSS Grid placement — with zero API breaks and 100% bit-exact layout parity.

## What Changed

### 1. CSS Animation Restamping (`internal/layout/reproject.go`, `layout/reproject.go`)
- **Two-pass ancestor-only `stampStateAt`:** Replaced full-tree `advanceStamp` traversal with a lightweight non-closure DFS (`findBoxAncestors`) that collects only the `[]*box` ancestor chain from `root` to `target`, then runs `advanceStamp` only on those ancestors while capturing `perspAncestor` in the same pass (eliminating the second `nearestPerspectiveAncestor` tree walk).
- **Pooled `restampScratch` & zero-copy patches:** Reused scratch slices across `RestampTransforms` via `sync.Pool`, preserved pristine op geometry across frames (zero allocs after frame 1), pre-bound target `effectsGroup` slots to avoid per-frame `editEffects()` cloning, and returned zero-copy 3-index sub-slices from `restampElementPatch` and `restampedBoxes` for single-window/single-range updates.
- **Test coverage:** Added `TestRestampNestedPreserve3DWithSiblings` in `internal/layout/reproject_test.go`.

### 2. Lock-Free ASCII Font Metrics & Single-Pass Text Indexing (`internal/fonts`, `internal/layout`)
- **Immutable `[128]` ASCII tables:** Precomputed `asciiGlyph [128]uint16`, `asciiAdv [128]int32`, and `ScaledFace.asciiPts [128]float64` once at font parse/scale time, plus `ScaledFace.MeasureSimpleASCII(text)` for lock-free, zero-allocation IEEE-754 bit-exact printable ASCII width summation.
- **Hoisted face/coverage lookups:** Hoisted `SharedScaledFace` out of per-rune loops in `accumulateTextFaceWidth` and `primaryRunWidth`, and deduplicated `faceFor` / `faceRunAllPrimary` calls in `emitInlineText`.
- **Single-pass `placedTextIndex` (`internal/layout/placed.go`):** Replaced repeated `node.TextContent()` subtree walks in `WalkPlacedWithOptions(..., IncludeText: true)` with a single `O(N)` buffer index, plus an `O(1)` short-circuit in `walkOperationOwnersParents` (`op_owners.go`).

### 3. DisplayList, Selector Match-Cache & Viewport `css.Relayout` (`internal/style`, `internal/layout`, `css`)
- **Unreferenced `id` elision (`ruleindex.go`, `style_match_cache.go`):** Tracked referenced `#id` and `[id...]` selectors on `RuleIndex` so unique element IDs (such as `id="row-1"` … `id="row-1000"`) share a single selector `matchCacheEntry`.
- **Pooled `childSlabs` & stack flex rows (`layout_chunks.go`, `flex.go`, `layout_flow.go`):** Pooled 256-entry `box.children` slabs recycled on `Result.Release()`, stack-allocated `[1][]flexMeas` for `flex-wrap: nowrap`, eliminated the duplicate DOM walk in `estimateOpCapacity`, and extended `inline_single.go` to handle single-line multi-word ASCII phrases without word splitting or coalescing builders.
- **`O(1)` viewport-only `css.Relayout` (`css/relayout.go`, `internal/convert/prepare/sheet_cache*.go`):** Tracked `viewportGating` on `SheetCache` so viewport-only relayouts reuse `registry`, `states`, and cloned `sheets` directly when no media-gated `<link>` or `@import` sheets are present.

### 4. CSS Grid Allocation Parity (`internal/layout/grid*.go`)
- Added pooled dense `[]uint64` row bitsets for grids with `<= 64` columns (`row < 4096`), keeping `map[int][]uint64` lazy for wide/sparse grids.
- Removed per-item closure allocations (`occ.freeAt`, `node.Walk`), eliminated `autoRowItemsByRow` `[][]int` staging, rewrote `tokenizeGridTracks` to slice directly without `strings.Builder`, and skipped `measureTrackIntrinsics` when no intrinsic tracks exist.
